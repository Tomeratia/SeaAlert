#  Dataset Access

The full dataset, including raw audio files (WAV), metadata, and processed CSVs, is hosted externally due to size constraints.

### [Download Full Dataset from Google Drive](https://drive.google.com/drive/folders/1X6kbNvaAN7yWJGcH8SU4fDIwbkNcOgdR?usp=sharing)

---

## Directory Structure (Drive)

The external drive contains:
1. **`audio_samples/`**: Representative audio clips (Clean vs Noisy).
2. **`data.zip`**: Complete archive of all generated audio and metadata.
3. **`metadata.csv`**: Overview table of all samples.

## Local Data Folder
This local `data/` directory contains:
- `processed/`: Helper CSVs for training and evaluation.
- `asr/`: Raw transcripts from the Whisper ASR model.
